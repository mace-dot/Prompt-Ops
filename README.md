# Prompt Ops

Tools for using AI chat products more efficiently — less fluff in prompts, clearer quota awareness.

## Quota Pilot

Chrome extension in [`quota-pilot-ext/`](./quota-pilot-ext/). Load that folder unpacked in Chrome (`chrome://extensions` → Developer mode → Load unpacked).

See [`quota-pilot-ext/README.md`](./quota-pilot-ext/README.md) for install and features.
